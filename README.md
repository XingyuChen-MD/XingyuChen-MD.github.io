# Xingyu Chen Academic Website

This repository hosts the personal academic website of Xingyu Chen, MD, MSc:

https://xingyuchen.org/

The site presents Xingyu's work at the interface of urologic oncology, cancer genomics, tumor immunology, functional genomics, AI-assisted biomedical research, and single-cell / spatial multi-omics.

## Website Scope

- Academic profile and research direction
- Selected publications and research record
- Curriculum vitae download
- Collaboration interests
- Contact and professional identity links

## Research Themes

- Tumor immune escape and cancer evolution
- Cancer genomics and computational oncology
- Single-cell and spatial multi-omics
- Functional genomics and mechanism discovery
- Biomarker discovery and translational oncology
- AI-assisted biomedical research workflows

## Repository Structure

- `index.html` - main website page
- `images/` - site images and portrait assets
- `docs/` - downloadable academic documents
- `CNAME` - custom domain configuration for `xingyuchen.org`
- `robots.txt` and `sitemap.xml` - search engine discovery files
- `.github/workflows/` - automated repository checks

## Maintenance Notes

The `main` branch is the production source for the public website. Keep public-facing files clean and avoid committing temporary archives, drafts, private notes, unpublished manuscripts, or sensitive data.

When updating the website:

1. Edit the relevant public files.
2. Confirm `index.html`, `CNAME`, `robots.txt`, and `sitemap.xml` are still present.
3. Check that local links and image paths still resolve.
4. Commit the update with a clear message.
5. Allow GitHub Pages a few minutes to publish.
