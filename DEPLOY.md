# Xingyu Chen Academic Website

This package is ready for GitHub Pages at `xingyuchen.org`.

## Publish

1. Open the repository `XingyuChen-MD/XingyuChen-MD.github.io` on GitHub.
2. Upload the contents of this package to the repository root, preserving the `images/` and `docs/` folders.
3. Commit the changes to the branch currently used by GitHub Pages.
4. In **Settings → Pages**, confirm the site is being published from that branch.
5. Keep the existing custom-domain and DNS settings. The included `CNAME` file preserves `xingyuchen.org`.

## Main files

- `index.html` — complete responsive website.
- `images/avatar.png` — portrait used in the hero section.
- `docs/Xingyu_Chen_CV.pdf` — downloadable July 2026 academic CV.
- `og.png` — social preview image.
- `favicon.svg`, `robots.txt`, `sitemap.xml`, `CNAME` — identity and search-engine files.

After publishing, allow GitHub Pages a few minutes to rebuild the site, then refresh `https://xingyuchen.org`.
